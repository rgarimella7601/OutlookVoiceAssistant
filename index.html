AI Voice Assistant for Outlook

Speak an email; get polished text in a side pane; insert it when you're ready.

Step 1 — Download your manifest

This button builds a manifest that points Outlook to this site:

This page isn't on an HTTPS web address. Open it from your GitHub Pages address (https://…github.io/…) and download the manifest there.

Step 2 — Add it to Outlook

  1. In new Outlook (or Outlook on the web), open aka.ms/olksideload — the Add-Ins window opens.
  2. Select My add-ins, scroll to Custom Addins, select Add a custom add-in › Add from File…
  3. Choose the manifest.xml you downloaded and confirm the install.

If you don't see “Add a custom add-in”, your organization blocks custom add-ins — ask IT to deploy this manifest for you.

Step 3 — Use it

  1. Start a new email or reply. On the ribbon (or the Apps button) select Voice Assistant.
  2. First time only: open the gear icon, paste your OpenAI API key, select Save.
  3. Select Start recording, choose Allow for the microphone, and talk.
  4. Edit the text if needed, then select Insert into Email.
